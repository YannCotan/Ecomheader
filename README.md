# Portfolio — Yann Cotan

Portfolio fullstack : **Vite + three.js + GSAP + Lenis** (JavaScript pur).

## Lancer
```bash
npm install
npm run dev      # développement
npm run build    # production → dist/
```

## Personnaliser
Tout le contenu (projets, expérience, stack, liens GitHub/LinkedIn) est dans `src/data.js`.
Les projets actuels sont des **exemples à remplacer**.
